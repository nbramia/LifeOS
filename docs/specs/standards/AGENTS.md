This directory contains coding and testing standards — rules for how we work on LifeOS.

## Contents

- `python-conventions.md` — Python naming, module layout, service patterns, logging rules
- `testing-standards.md` — Test organization, fixtures, markers, remote testing workflow

## Key Principles

- These are **rules, not suggestions**. Code review should enforce them.
- When LifeOS conventions conflict with general style guides, LifeOS conventions win.
- Standards evolve — update when the team agrees on a new convention, not before.
