This directory contains vision documents — why LifeOS exists and the philosophy guiding its design.

## Contents

- `philosophy.md` — Project vision, problem statement, guiding principles, and scope

## Key Principles

- Vision documents describe the **WHY** — the enduring purpose and philosophy.
- Updated rarely — only when strategic direction fundamentally changes.
- Not a roadmap (that's `plans/`). Not a design doc (that's `specs/`).
